# Publish v1.0 to GitHub

## Before publishing

1. Review all documents/screenshots, confirm ownership and remove any sensitive information.
2. Restore the supplied `.zap21` in Siemens TIA Portal V21 if possible and verify the project. Do not use a historic SCL snapshot as an authoritative export.
3. Review `plc/exported/PLC_CNC_Cell_Full_Source_Export.scl` (5 FBs, 12 DBs, 4 UDTs). The graphical Main [OB1] is provided as an image; the complete engineering configuration requires the separately held `.zap21` archive.
4. The original `.zap21` contains generated runtime/user-management configuration and historic backups. Do **not** upload it publicly until reviewed.

## Easy publish (GitHub website)

1. Sign in to GitHub and create a **public** repository named `siemens-s7-1500-robotic-cnc-cell` with **no autogenerated README**.
2. Extract this ZIP locally. Upload the **contents** of the extracted folder to your new GitHub repository using **Add file → Upload files**.
3. Commit the files. Open README and verify images display.
4. Select **Releases → Draft a new release**. Set a new tag `v1.0.0` targeting `main`. Use `RELEASE_NOTES_v1.0.md` as the release notes. Publish the release.
5. Optionally attach a re-archived, reviewed `.zap21` as a release asset. Avoid putting binaries in source Git history.

## Git Bash alternative

```bash
git init -b main
git add .
git commit -m "release: robotic CNC cell simulation v1.0.0"
git tag v1.0.0
git remote add origin https://github.com/YOUR_USERNAME/siemens-s7-1500-robotic-cnc-cell.git
git push -u origin main
git push origin v1.0.0
```

**Note:** This folder includes exported source plus historical reference snapshots. Independent reproduction of the complete PLC+HMI project still requires the reviewed `.zap21` archive and a Siemens TIA Portal restore/compile.
