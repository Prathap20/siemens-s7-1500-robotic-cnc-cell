# Historical source-body snapshots

These controller bodies were pasted during development. They are **not an authoritative export of the compiled, online TIA Portal v21 PLC project** and exclude FB declarations, possibly later online edits, global DB definitions and UDTs. They are included as reference for discussions of the project architecture and recoveries, not as drop-in `.scl` build artifacts.

Do not copy these into `plc/exported/` without comparing against the final TIA Portal blocks and testing the result.
